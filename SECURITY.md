# Report a security problem

Use the affected repository's **Security** tab, then select **Report a vulnerability**.
GitHub sends this report privately to the repository maintainers.
Do not open a public issue with credentials, customer data, or exploit details.

Include the affected commit, steps to reproduce the problem, expected behavior, and actual behavior.
Use sample data and a local installation when possible.
Describe which accounts or permissions the problem requires.
Do not test against another person's deployment without permission.

The project accepts reports for the code on `main`.
There is no supported production release or guaranteed response time yet.
The local setup uses older dependencies and is not a production deployment guide.
